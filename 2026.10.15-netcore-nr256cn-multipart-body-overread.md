# Out-of-Bounds Read in Multipart Upload Parsing via Unterminated Body Search

- Published: 2026-10-16
- Supplier: Netcore
- Product: NR256CN
- Affected version: NR256CN-V1.5.140116.bin
- Vulnerability type: Out-of-Bounds Read (CWE-125)
- Contributors: Zhou Ao, Yin Luxing, Lu Fangzhou, Liu Xin @Nebusec

## Affected Component / Code Path
- multipart upload routes such as `/router/filter_arp_put_file.cgi`
- `read_body.c`
- `write_body.c`

## Disclosure Note
This public reference is intentionally limited to identification details required for CVE coordination.
Proof-of-concept material, reproduction steps, and additional technical detail are withheld at this stage.

## Summary
Multipart upload parsing searches the buffered request body for multipart markers with strstr() although the buffered body is never NUL-terminated. A marker-free upload body makes the search continue past the received bytes and potentially past the 32 KiB request buffer.

## Impact
A remote attacker can crash the web management service with a crafted multipart upload body.
