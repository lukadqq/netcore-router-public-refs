# Pre-authentication Stack Buffer Overflow via a Long Basic-Auth Username in user_ok

- Published: 2026-10-16
- Supplier: Netcore
- Product: NR256CN
- Affected version: NR256CN-V1.5.140116.bin
- Vulnerability type: Stack-Based Buffer Overflow (CWE-121)
- Contributors: Zhou Ao, Yin Luxing, Lu Fangzhou, Liu Xin @Nebusec

## Affected Component / Code Path
- `/router/*.cgi` protected management routes
- `process_header_end.c`
- `user_auth.c`
- `user_ok.c`

## Disclosure Note
This public reference is intentionally limited to identification details required for CVE coordination.
Proof-of-concept material, reproduction steps, and additional technical detail are withheld at this stage.

## Summary
The Basic-authentication username remains attacker-controlled after Base64 decoding and the user and password split, and user_ok() copies it with strcpy() into two fixed 64-byte stack buffers before the password check runs over IPC. A decoded username longer than 63 bytes therefore overflows the stack before authentication completes.

## Impact
An unauthenticated remote attacker can corrupt the stack of the web management service with a single request, crashing the device and potentially executing arbitrary code.
