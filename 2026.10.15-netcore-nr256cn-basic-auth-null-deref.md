# NULL Pointer Dereference in Basic-Auth Parsing Before Authentication Failure Handling

- Published: 2026-10-16
- Supplier: Netcore
- Product: NR256CN
- Affected version: NR256CN-V1.5.140116.bin
- Vulnerability type: NULL Pointer Dereference (CWE-476)
- Contributors: Zhou Ao, Yin Luxing, Lu Fangzhou, Liu Xin @Nebusec

## Affected Component / Code Path
- `process_option_line.c`
- `process_header_end.c`
- `user_auth.c`

## Disclosure Note
This public reference is intentionally limited to identification details required for CVE coordination.
Proof-of-concept material, reproduction steps, and additional technical detail are withheld at this stage.

## Summary
user_auth() decodes the Basic-authentication header value and writes through the pointer returned by strchr(value, ':') without checking that a colon was found. A decoded value without a colon triggers a NULL-pointer write before the authentication failure handling runs.

## Impact
An unauthenticated remote attacker can crash the web management service with a single malformed request.
