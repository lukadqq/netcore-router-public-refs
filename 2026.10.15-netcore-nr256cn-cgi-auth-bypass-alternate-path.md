# Authentication Bypass on Protected Management CGI Handlers via Public-Route URI Prefixes

- Published: 2026-10-16
- Supplier: Netcore
- Product: NR256CN
- Affected version: NR256CN-V1.5.140116.bin
- Vulnerability type: Authentication Bypass Using an Alternate Path (CWE-288)
- Contributors: Zhou Ao, Yin Luxing, Lu Fangzhou, Liu Xin @Nebusec

## Affected Component / Code Path
- `/router/get_user_type.cgi` and other protected `/router/*.cgi` handlers
- `l7_web_auth.cgi` URI prefix and `.ico` path segments
- `cgitest.cgi`
- `process_header_end.c`
- `translate_uri.c`
- `init_cgi.c`

## Disclosure Note
This public reference is intentionally limited to identification details required for CVE coordination.
Proof-of-concept material, reproduction steps, and additional technical detail are withheld at this stage.

## Summary
The HTTP server marks a request public before authentication when the request path begins with the l7_web_auth.cgi or l7_web_auth_text_show.cgi prefix or contains .ico. Any .cgi path is classified as CGI and always handed to the single cgitest.cgi dispatcher together with the original request path, so protected management handlers wrapped in such a prefix are reachable without authentication.

## Impact
An unauthenticated remote attacker can invoke protected management CGI handlers and read or change router management state.
