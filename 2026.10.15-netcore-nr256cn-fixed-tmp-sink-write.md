# Unauthenticated Writes to Predictable Fixed Temporary Files via Arbitrary CGI Pathnames

- Published: 2026-10-16
- Supplier: Netcore
- Product: NR256CN
- Affected version: NR256CN-V1.5.140116.bin
- Vulnerability type: Insecure Temporary File (CWE-377)
- Contributors: Zhou Ao, Yin Luxing, Lu Fangzhou, Liu Xin @Nebusec

## Affected Component / Code Path
- `boa_temp.update` and `boa_temp.para` fixed sink files in the device temporary directory
- `translate_uri.c`
- `process_header_end.c`
- `write_body.c`

## Disclosure Note
This public reference is intentionally limited to identification details required for CVE coordination.
Proof-of-concept material, reproduction steps, and additional technical detail are withheld at this stage.

## Summary
Any .cgi pathname is accepted as a CGI request without checking that the route exists. The POST body sink is selected from pathname substrings into fixed, predictable files (boa_temp.update and boa_temp.para) in the device temporary directory, and the body is streamed into the selected file without secure temporary-file creation.

## Impact
An unauthenticated remote attacker can overwrite predictable files on the device with attacker-controlled data, enabling tampering with staged update data and denial of service.
