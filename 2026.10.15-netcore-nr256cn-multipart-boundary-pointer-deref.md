# Invalid Boundary Pointer Dereference during CGI Handoff on Multipart Uploads

- Published: 2026-10-16
- Supplier: Netcore
- Product: NR256CN
- Affected version: NR256CN-V1.5.140116.bin
- Vulnerability type: Untrusted Pointer Dereference (CWE-822)
- Contributors: Zhou Ao, Yin Luxing, Lu Fangzhou, Liu Xin @Nebusec

## Affected Component / Code Path
- multipart upload routes such as `/router/put_file.cgi`
- `process_option_line.c`
- `write_body.c`
- `cgitest.cgi`

## Disclosure Note
This public reference is intentionally limited to identification details required for CVE coordination.
Proof-of-concept material, reproduction steps, and additional technical detail are withheld at this stage.

## Summary
The header parser saves the offset after the boundary= parameter of the multipart Content-Type without checking that the parameter is present, and the CGI handoff later calls strlen() on the saved pointer. A multipart request without a boundary parameter dereferences an invalid pointer while CGI arguments are prepared.

## Impact
A remote attacker can crash the request-handling path with a single malformed upload header.
